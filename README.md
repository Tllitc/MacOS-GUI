# macOS GUI 采集标注工具

一款基于 Python + PyQt5 开发的 macOS 端 GUI 操作轨迹采集和标注工具。

## 功能特性

- ✅ 支持 11 种软件类型分类（社交、电商、办公、浏览器等）
- ✅ 全屏截图和区域选择（拉框/点击）
- ✅ 完整的动作标注（意图、CoT、UI元素、坐标等）
- ✅ 支持多种动作类型（点击、拖拽、输入、滚动等）
- ✅ 分页式步骤编辑，支持撤销上一步
- ✅ 自动化的文件命名和目录结构管理
- ✅ 全局快捷键支持（Ctrl+Q 截图，Ctrl+S 保存）
- ✅ Answer 模式支持（step 重新计数）
- ✅ 符合样例数据格式的 JSON 输出

## 系统要求

- macOS 10.13+ 
- Python 3.7+
- PyQt5

## 安装依赖

```bash
pip install -r requirements.txt
```

## 快速开始

### 1. 运行程序

**推荐方式**：使用启动脚本（自动配置环境）
```bash
./run.sh
```

**或者直接使用虚拟环境**：
```bash
.venv/bin/python main.py
```

**⚠️ 重要提示**：
- 首次运行需要授予**屏幕录制权限**（见下方"常见问题"）
- 如果启动失败，请查看 [启动问题解决指南.md](启动问题解决指南.md)

### 2. 创建新任务

1. 选择软件类型（社交、电商、办公等 11 种）
2. 输入具体软件名称（如：网易有道翻译）
3. 输入任务指令（可选）
4. 点击"开始标注"

### 3. 标注流程

#### 捕获截图
- **方法一**：点击界面上的"捕获新截图"按钮
- **方法二**：按全局快捷键 `Ctrl+Q`

窗口会自动隐藏，进入全屏截图模式：
- **点击**：在屏幕上单击选择某个点
- **拉框**：按住鼠标左键拖动选择区域

释放鼠标后自动截取选中区域并返回编辑界面。

#### 填写动作信息

在右侧表单中填写：
- **意图**：这个动作的目的（如：左键单击网易有道翻译）
- **CoT**：为什么要这么做（思维链）
- **活动窗口**：当前活动的窗口名称
- **UI元素**：操作的 UI 控件名称
- **动作类型**：选择具体的动作类型
  - `left_click`：左键单击
  - `double_click`：双击
  - `triple_click`：三击
  - `right_click`：右键单击
  - `mouse_move`：鼠标移动
  - `left_click_drag`：拖拽
  - `type`：文本输入
  - `keys`：按键组合
  - `scroll`：滚动
  - `wait`：等待
  - `answer`：回答用户
  - `terminate`：终止任务
  - `Finish`：完成标注

根据选择的动作类型，会显示相应的参数输入框（坐标、文本、按键等）。

#### 保存步骤

- **方法一**：点击"保存当前步骤"按钮
- **方法二**：按全局快捷键 `Ctrl+S`

#### 导航步骤

- 使用"← 上一步"和"下一步 →"按钮在不同步骤间切换
- 可以修改之前步骤的信息

#### 撤销操作

点击"撤销上一步"可以删除最后添加的步骤（包括截图文件）。

### 4. 完成标注

当所有步骤标注完成后，点击"完成标注"按钮：
1. 系统会自动生成符合规范的 JSON 文件
2. 所有截图按规则命名保存
3. 询问是否开始新任务

## 数据格式

### 目录结构

```
mac/                          # 一级：平台
└── 效率工具/                  # 二级：软件类型
    └── 网易有道翻译/          # 三级：软件名称
        ├── gui_000001.json   # 四级：任务数据
        ├── gui_000001_0001.png
        ├── gui_000001_0002.png
        └── ...
```

### JSON 数据结构

参考 `gui_000001.json` 样例文件，包含：
- 平台信息
- 系统信息
- 屏幕尺寸
- 任务指令
- 消息列表（user instruction + assistant trajectory）
- 轨迹步骤（每步包含 intent, CoT, observation, actions）

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Q | 隐藏窗口并开始截图 |
| Ctrl+S | 保存当前步骤 |
| ESC | 取消截图 |

## 注意事项

1. **Answer 模式**：当选择 action 为 "answer" 后，后续步骤的 step 编号会从 1 重新开始，但截图文件名继续累加
2. **Finish 动作**：选择 Finish 表示任务完成，点击后会触发保存流程
3. **坐标系统**：所有坐标都是相对于屏幕左上角的绝对像素坐标
4. **截图格式**：统一使用 PNG 格式保存
5. **权限问题**：首次运行时 macOS 可能会请求屏幕录制权限，请允许

## 开发说明

### 项目结构

```
├── main.py                 # 主程序入口
├── data_manager.py         # 数据管理模块
├── screenshot_capture.py   # 截图捕获模块
├── annotation_editor.py    # 标注编辑器模块
├── hotkey_listener.py      # 全局快捷键监听
├── requirements.txt        # 依赖包列表
└── README.md              # 说明文档
```

### 核心类说明

- **InitTaskWindow**：任务初始化窗口
- **AnnotationEditor**：标注编辑器主窗口
- **StepEditorWidget**：单个步骤的编辑界面
- **ScreenshotCaptureWindow**：全屏截图和区域选择窗口
- **DataManager**：数据和文件管理
- **GlobalHotkeyListener**：全局快捷键监听器

## 常见问题

### Q: 截图时看不到其他应用程序？
A: 确保已授予终端或 Python 屏幕录制权限（系统偏好设置 -> 安全性与隐私 -> 隐私 -> 屏幕录制）

### Q: 快捷键不生效？
A: 确保安装了 pynput 库，并且程序有辅助功能权限

### Q: 如何修改已有的标注数据？
A: 目前版本暂不支持加载已有数据进行编辑，建议重新标注
